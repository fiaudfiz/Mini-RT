# Security Policy

## Supported Versions

Security updates are currently provided for the latest version available on the `main` branch.

As Mini-RT is under active development, older versions may not receive security updates.

## Reporting a Vulnerability

If you discover a potential security vulnerability in Mini-RT, please report it privately rather than opening a public GitHub issue.

You can report vulnerabilities by contacting the project maintainers:

**Contact:** michelouali0@gmail.com

Please include the following information:

- A description of the vulnerability.
- Steps to reproduce the issue.
- The potential impact.
- Relevant logs, input files, or proof of concept, if available.

## Scope

Security reports may include, but are not limited to:

- Buffer overflows and out-of-bounds memory accesses.
- Memory leaks and invalid memory accesses.
- Integer overflows and unsafe arithmetic operations.
- Malformed or malicious `.rt` scene files.
- Unexpected crashes or undefined behavior.
- Improper input validation.

## Disclosure Policy

Please allow the maintainers reasonable time to investigate and address reported vulnerabilities before publicly disclosing them.

The maintainers will acknowledge reports and communicate the outcome of their investigation whenever possible.

Thank you for helping keep Mini-RT secure.
